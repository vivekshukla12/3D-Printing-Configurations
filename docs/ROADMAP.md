# Roadmap

## Near term

- Add metadata files to all existing profiles.
- Add validation records for successful hardware variations.
- Add a dedicated validation-record JSON Schema.
- Add automated schema validation with GitHub Actions.
- Normalize existing YAML field names and units where needed.

## Medium term

- Generate a compatibility matrix from metadata and validation records.
- Add profile comparison tooling.
- Add contribution templates for calibration submissions.
- Add multiple purpose-specific speed profiles where justified, such as quality, standard, fast, and draft.

## Long term

- Publish a searchable static website.
- Expose a machine-readable profile index.
- Support automated Bambu Studio profile generation or export.
- Build confidence scoring from independent successful validations.

Roadmap items are proposals, not established architecture. Architectural changes require an ADR.
