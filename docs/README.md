# Documentation

This directory defines the repository architecture, contribution rules, schema conventions, AI usage rules, roadmap, and accepted design decisions.

Start here:

- `REPOSITORY_ARCHITECTURE.md`
- `AI_USAGE.md`
- `CONTRIBUTING.md`
- `SCHEMA_REFERENCE.md`
- `ROADMAP.md`

The repository is intended to serve as a structured, version-controlled knowledge base for 3D printer filament profiles, calibration results, speed settings, validation records, and test history.
