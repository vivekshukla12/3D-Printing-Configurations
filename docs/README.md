# Documentation

This directory defines the repository architecture, contribution rules, schema conventions, AI usage rules, roadmap, and accepted design decisions.

Start here:

- `REPOSITORY_ARCHITECTURE.md`
- `AI_USAGE.md`
- `CONTRIBUTING.md`
- `SCHEMA_REFERENCE.md`
- `ROADMAP.md`
- `decisions/`

Reusable AI-agent workflows are stored separately under the repository-level `skills/` directory. Their architecture and authority model are defined by ADR `decisions/0013-reusable-ai-agent-skills.md`.

The repository is intended to serve as a structured, version-controlled knowledge base for 3D printer filament profiles, calibration results, speed settings, validation records, test history, and the reusable AI workflows used to retrieve and maintain that knowledge.
