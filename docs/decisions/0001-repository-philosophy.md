# ADR 0001: Repository Philosophy

## Status
Accepted

## Date
2026-08-04

## Context
The repository is intended to preserve reproducible 3D-printing knowledge rather than act only as a backup of the latest slicer settings.

## Decision
Treat the repository as a structured, version-controlled knowledge base for manufacturer defaults, calibrated profiles, speed profiles, calibration results, validation history, and practical notes.

## Consequences
- Historical evidence is preserved.
- Human and AI consumers can distinguish defaults, recommendations, and validated results.
- Repository structure and schemas become part of the product.
